UE4製ゲームを
翻訳・修正する方法
（.locres なし）

2026/03/10

有志翻訳Modderへの参考として。
Filament という、UE4製ゲームの機械翻訳を修正したときの手順です。

ゲーム概要：

  • Unreal Engine 4.24 製
  • ローカライズファイル（.locres）なし
  • アセット（.uasset）に字幕テキストが入ってる

作業の流れ

tips.
ゲームフォルダ はどこ？
  1. Steamライブラリ　>　⚙ 歯車マーク

  2. 管理　>　ローカルファイルを閲覧

    ……で出てくるのが、ゲームフォルダ

1
ゲームエンジンを調べる
  • Unreal Engine か、Unity か、それとも別か？
  • ゲームフォルダ を開く
    →　ゲームの実行ファイル（.exe）を右クリック
    →　プロパティ
    で調べた。UE 4.24 だった。

close
2
.pak を探す
  • ゲーム内のコンテンツは、.pak（パッケージ・ファイル）にまとめられている。
    ※ .ucas .utoc の場合あり
  • ゲームフォルダ 直下か、「ゲーム名/Content/」から Paksフォルダ を探す。
    ここに.pak が入っている。

  • .pak はそのままじゃ開けない。
    .zip みたいに解凍もできるけど（アンパック）、容量がデカい。

    まずは中身を見るツールで、ゲーム内の字幕や、翻訳テキスト がどのファイルに入ってるか探す。
    今回は FModel を使った。

📌 FModelでできること …… .pak (.ucas, .utoc) の中を見る、ファイル名検索、.json出力、.uasset出力

close
3
.pak の中を見る、検索する　／ツール - FModel

《1》起動

  • FModel を起動すると、ゲームを自動検知してくれる。
  • 検知しない時は手動入力。
    適当な設定名をつけて、Paksフォルダ のパスを入れる。

    拡大

《2》読み込む .pak を選ぶ

  • Archives タブ　>　Loading Mode　>　All
  • Load ボタンを押すと、.pak が全部読み込まれる。

拡大

📌 Loading Mode

・ Multiple :　選択した .pak だけ読み込む（複数可）
・ All :　全部読み込む

《3》.pak の中を検索

  • Folders タブへ。
    ここが .pak の中身。フォルダ・ファイルが一覧になって出てくる。
  • 左からゲーム名のフォルダ（ルートフォルダ）を選ぶ。
    Ctrl + Shift + Pで「ファイル名の検索」をしてみよう。
    • 今回は公式訳があるので、.locres（ローカライズの翻訳ファイル）を探した。　→　無し
    • local　log　message　text　jp　など字幕に関係しそうなファイル名で探す。　→　.uassetがいくつかヒット
    • 検索結果からファイルサイズ 800kb-1Mb あたりを内容確認したが、見つからないテキストがある。　→　全文検索へ
  • .locres がある場合は、こちらが参考になりそう：　翻訳Modderの為の忘備録 - Yararezon

close
4
全文検索　／ツール - Inazuma Search
  • FModel の検索で、ゲームテキストがいくつかのファイルに分散してるとわかった。
    ファイル名検索だけじゃ探しきれない。
  • 今のところ、FModel では全文検索ができない。
    .pak の中身を全部 JSON で取り出して、テキスト用の全文検索ツールで探すことにした。
    今回は Inazuma Search を使う。

《1》JSON出力

  1. まずは FModel

    上部メニュー Setting　>　General　>　Output Directory で出力先を決めておく。

  2. ゲーム名のフォルダ（ルートフォルダ）を右クリック　>　(.json) で出力。

    拡大

《2》全文検索

  1. つぎに Inazuma Search

    • 右上の ⚙ 設定　>　検索対象フォルダ を追加。JSONが入ったフォルダを選ぶ。
    • そのまま、右下にある ⚙ 詳細設定と特殊機能 へ進む。

    拡大

  2. ここで .jsonを 追加 すると、JSONファイルの全文検索ができるようになる。

    拡大

  3. あとは最初の画面に戻って クロール ボタンを押し、しばらく待つ。

    クロールが終わったら、ゲーム内の固有名詞・セリフなどで検索。ゲーム内テキストが入ったファイルを全部特定する。特定したファイル名とパスはメモっておく。

📌今回は、メインストーリーのテキストが 3つのファイルに入ってて（.uasset、.umap）、どれが実際ゲーム内に影響してるのかわからなかった。
【6 .uasset編集】で「これは」「これハ」「これワ」とわざと変えて保存し、ゲーム内で文章を確認して突き止めた。

5
.pak から .uasset を取り出す

FModel に戻る。
さっき突き止めたファイル名で検索。ヒットしたファイルを右クリック　>　(.uasset)で出力。

📌 場合によっては .uasset と .uexp がセットなこともある（.uasset がヘッダー、.uexp が実データ）。
その場合は一緒に出力してくれるらしい。UAssetGUI での編集 や .pak化 するときも、セットで入れる必要がある。

📌 今回は、メインストーリーのファイルだけ .umap だった。.uasset と同じように扱っていいっぽい。出力も編集も同じ方法でできた。

close
6
.uasset を編集する（翻訳作業）　／ツール - UAssetGUI

やっと翻訳作業。私の手順はこんな感じ：

  1. 英語原文をコピー
  2. AI／機械翻訳をかける
  3. 都度細かいニュアンスを深掘り、修正
  4. 修正した訳をオリジナルと置き換える

1と4に UAssetGUI を使った。

拡大

UEのバージョンをちゃんと入れさえすれば、あとは .uasset ファイルを開くだけ。

左にずら～っと並んでる Export 1, 2, 3....にデータが色々入ってるので、どこに目当てのテキストが入ってるか探す。見つかったらコピーなり置換なりして、保存。

データが多い時は検索も使うとよし（結構時間がかかる）。

📌 今回は元データと翻訳のバイト数を揃えなくても良かったけど、場合によってはその必要があるかも（特に .uasset と .uexp がセットのとき）。まず試しに一単語のバイト数を変えて保存して（私の → 私のの 等）、字幕が反映されるか確認してから作業を進めること。
